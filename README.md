# الأمن السيبراني من الصفر

أكاديمية تفاعلية بالعربي (عامية مصرية) لتعلم أساسيات الأمن السيبراني من الصفر تماماً، جزء من منصة أكاديميات Infinity University Activity.

**الموقع المباشر:** https://capwv.github.io/cyber-from-zero/

## المحتوى

- **14 درس متدرج** (13 درس + مشروع ختامي): من "إيه هو الأمن السيبراني؟" لحد المراجعة الأمنية الشخصية الكاملة
- **42 سؤال تفاعلي** بتصحيح فوري وشرح لكل إجابة
- **28 تمرين عملي** بمحاولات وكشف حل نموذجي
- **معمل أمن تفاعلي** داخل المتصفح بـ 13 تحدي:
  - آلة شفرة قيصر (تشفير وفك تشفير بأي إزاحة) + 5 تحديات فك شفرة بتتصحح تلقائياً
  - مقياس قوة باسورد بيحسب وقت التخمين التقريبي بنموذج موثق (10 مليار محاولة/ثانية، هجوم offline على hash سريع)
  - لعبة اصطاد الـ Phishing: 8 رسايل تدريبية مع شرح العلامات الحمرا لكل واحدة
- تتبع تقدم محلي (localStorage) لكل درس وسؤال وتمرين
- المحتوى كله تعليمي ودفاعي: مفيش أي تعليمات هجومية

## الدروس

1. إيه هو الأمن السيبراني؟
2. مثلث CIA: السرية والسلامة والتوافر
3. التهديدات والمهاجمين
4. الباسوردات والـ Authentication
5. الـ Phishing والهندسة الاجتماعية
6. أنواع الـ Malware
7. الشبكات والـ Firewalls
8. التشفير من الصفر
9. ثغرات الويب: XSS و SQL Injection (مفاهيمي)
10. دليل تأمين نفسك أونلاين
11. الخصوصية على الإنترنت
12. لو حصلك اختراق: الاستجابة والنسخ الاحتياطي
13. الشغل في الأمن السيبراني
14. المشروع الختامي: المراجعة الأمنية الشخصية

## التقنية

صفحة واحدة (index.html) بدون أي build: HTML + CSS + JavaScript خام، أدوات المعمل مكتوبة بالكامل بـ JavaScript (lab-core.js + lab.js)، خلفية متحركة مشتركة (sams-bg.js)، وتصميم داكن متجاوب مع الموبايل.

## التشغيل محلياً

افتح `index.html` مباشرة في المتصفح، أو:

```bash
python -m http.server 8000
```
